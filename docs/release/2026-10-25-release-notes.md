# Tailor It リリースノート(2026-10-25・Day2 デモ版)

> 対象: 本番(main = Day1 版・PR #40 の時点)から、今回のリリース(develop → main)で増える分。PR #54 以降。
> 「**統合 PR マージ後**」と書いた行は、10/24 夜にレビュー待ちだった PR を 1 本にまとめた統合 PR(`integration/bundle-1025`)がマージされてから入る。
> 手順は [`2026-10-25-runbook.md`](2026-10-25-runbook.md)。

## 作る・直す
- 作る前に、足りないところだけ 1〜3 問聞いてから作れるようになりました(設定でオフにできます)。(#92 #105)
- その質問がすぐ返ってくるようになりました(質問が出始めるまで 1 秒弱 → 0.3 秒)。(#159)
- 声で質問に答えたら、そのまま自動で作り始めます。最初の待ちも短くなりました。(#163・統合 PR マージ後)
- アプリができあがるまでが速くなり、画面の枠が約 2.4 秒で出始めます。(#94)
- 前回作ったアプリが起動時にそのまま戻り、「元に戻して」「別のアプリ」も声で言えます。(#57 #88)
- マイクを長押しすると作ったアプリの一覧(変身一覧)が出て、声でも切り替えられます。(#72)
- 画面のつながりを図で見て、画面を選んでから声で直せます(画面マップ)。(#144)
- 「B の画面からも C へ行けるように」のように、画面の分け方や行き先を声で変えられます。(#128)
- 画面の移動が賢くなり、何度行き来しても戻るボタンが深くなりません。(#126)
- 言ったのに機能が無い・名前と中身が違う、ということが大きく減りました(機能の充足 49% → 88%・嘘のラベル 0/20)。(#111 #124 #135)
- さらに充足 91% に。デモで言う 18 の言い方(割り勘の精算・読み上げボタンの位置など)も直しました。(#173 #174・統合 PR マージ後)
- カードやセクションの中でも 2 列に並べられるようになりました。(#161・統合 PR マージ後)
- 作ったアプリを、単体のアプリとしてリリースしてほしいと申請できます。(#145)
- 新しく作るのは無料で 1 日 3 回まで。月額の「Tailor It Pro」で無制限になります(作ったアプリを直すのは回数に数えません)。(#166・統合 PR マージ後)

## 計算
- 割り勘の精算・BMI・残り予算などを、アプリの中で計算できるようになりました。(#117)
- 一覧からワンタップでチェック、今週 / 今年での絞り込み、時刻の差(勤務時間 × 時給など)ができます。(#127)
- 「今の体重」のように最新の 1 件を出す、別の記録の値を読む、毎日リセットされるチェックができます。(#141)

## 見た目
- 名前が「Tailor It」になり、アイコンと色(藍 × 生成り)も新しくなりました。(#91 #95 #123)
- 作ったアプリの見た目をそろえ、入力・ボタン・一覧・数字の表示を作り直しました。ダークモードにも対応しています。(#56 #103)
- 日付に曜日が付き、進捗バーの意味が分かりやすくなりました。フォームの切れや余白の崩れも直しました。(#139 #146)
- 「¥ 800 円」の二重表示や、ボタン・通知の重なりなど細かい表示を直しました。(#90 #97 #156)
- マイクのボタンをドラッグで動かし、画面の端に隠せます(位置は覚えます)。(#110)
- 文字の大きさの設定・VoiceOver・視差効果を減らす設定に対応し、色のコントラストも上げました。(#98)
- キーボードを出しても入力欄と保存ボタンが隠れません。(#151・統合 PR マージ後)
- 長い一覧の最後の行がマイクに隠れなくなりました。(#170・統合 PR マージ後)

## 共有
- 作ったアプリを QR コードやリンクで渡せます。公開されたアプリを「探す」で見つけて入れられます。(#118)
- 掲示板のような「みんなで使うアプリ」が作れ、投稿は約 0.5 秒で他の人の端末に出ます。(#93 #104)
- LINE・Slack・Discord に送るボタンや、Web ページを表示する部品を使えます。(#54)
- 近くの端末に記録を送れます(相手の承認が必要・暗号化)。(#138)

## 話す
- 起動時に挨拶します。(#72)
- 挨拶・質問・できあがりの説明を読み上げられます(最初はオフ)。(#125)
- Siri やショートカットから、記録の追加・アプリを開く・話しかけることができます。(#120)

## 英語
- 画面の文字が英語に対応し、その場で言語を切り替えられます。(#129)
- 英語で話すと英語のアプリができます。(#58)
- 英語で作ったアプリの言葉や単位の崩れを直しました。(#149)

## 端末の機能
- ホーム画面のウィジェットに、作ったアプリの数字(今月の支出など)を出せます。(#55)
- タイマーがアプリを閉じても正確に動き、終わったら通知します。(#136)
- 端末内の Apple Intelligence で、要約・分類・書き直しをする部品を使えます(iPhone 15 Pro 以降)。(#137)
- 電波が無いところでも記録は先に保存され、つながったら自動で送ります。(#70)

## 安心・安全
- 電波が悪い・混んでいる時は自動で送り直し、失敗したら「もう一度」で再試行できます。(#96)
- アプリから開けるリンクは、許可した種類だけに限っています。(#54)
- 設定から「アカウントを削除」ができ、自分のアプリと記録がサーバーからすべて消えます。(#175・統合 PR マージ後)
- 「探す」に載せられるのはアプリを作った本人だけになり、インストール数の水増しも防ぎます。(#162・統合 PR マージ後)
