## 4. 直していないもの(報告)

- **金額欄の「¥ 0 円」**: currency の field に unit「円」が付く。#156(feature/money-display)で解消済み。**デモ前に #156 のマージが必要**
- **stat のラベルの単位が二重**(「今日の合計回数(回)」→「3 回」): count 用の規則「単位はラベルに書く」を sum の stat にも当てはめた。stat に unit が無い(スキーマは numberField だけ)ので、規則の言い直しか stat.unit の追加が要る。1 周でしか出ておらず、確かめる周回が残っていないので見送り
- **家計簿のタブが回で揺れる**: 同じ発話でタブ無し / 「ホームとグラフ」の 2 タブ。台本の「ホームと集計の 2 タブで…」の読み上げや §1.1 案 1 の「集計の画面からも…」は毎回は成り立たない
