# ai eval: 表示言語 locale(ja / en)(2026-10-24)

`POST /v1/generate` に `locale`(ja|en・省略時は発話から判定)を追加し、UI 文言・summary・undo 応答を英語でも返せるようにした後の確認。手順・前回値は [2026-10-24-catalog.md](2026-10-24-catalog.md)。生 JSON は `raw/2026-10-24-claude-sonnet-5-5-low-locale.json`(英語 4 本)と `raw/2026-10-24-claude-sonnet-5-5-low-locale-forced.json`(`-locale en` 強制 1 本)。

```sh
cd backend && set -a && source ../.env && set +a
go run ./cmd/ai-eval -effort low -model claude-sonnet-5-5 -tag locale \
  -only habit_en,books_en,walk_en,edit_books_rating_en
go run ./cmd/ai-eval -effort low -model claude-sonnet-5-5 -tag locale-forced -locale en -only kakeibo_short
```

## 1. 仕組み

| 層 | 変更 |
|---|---|
| API | `GenerateRequest.locale`(ja/en)。省略時 `ai.DetectLocale`: 発話にかな・漢字があれば ja、無ければ en。不正値は 400。応答に `locale` を返す |
| system prompt(固定・キャッシュ) | 「UI 文言はすべて日本語」→「user ターンの `## 表示言語(locale)` に従う」。表示文字列の列挙(app.name / tab.title / label / placeholder / emptyText / confirmMessage / enum options / notifications …)と、構造(id / type / enum 値 / area)は言語不問の注記。en few-shot `examples/expense_en.json`(home+form+通知 1 本)を例 2 として追加。代替の一言は en なら "replaced with" |
| user ターン(可変) | 先頭に `## 表示言語(locale)` 1 行(`ja(日本語)` / `en (English): write every user-facing string in natural English`)。system は変えないのでキャッシュは維持 |
| summary(create) | `summarizeFor(app, loc)`: ja は従来 `summarize`、en は `summarizeEN`("I made a Habit Tracker app. It has 2 tabs: Today and History. Use the button at the bottom right to add daily checks. You'll get a reminder every morning at 7.") |
| summary(edit) | PatchDocument の summary を locale の言語で書く(en は 80 字程度・ピリオド止め。満たされていれば "It's already ...") |
| undo | 「戻せる変更がありません。」/ "There is nothing to undo."、「ひとつ前の状態(version n)に戻しました。」/ "I went back to the previous state (version n)." |
| キーワード判定 | `wantsUndo`: 英語 prefix(`undo / go back / revert / roll back / never mind / scrap that / cancel that / take that back / forget it`)・英語は 32 文字以内(日本語は従来の 16)。`wantsNewApp`: `new app / different app / start over / from scratch / rebuild`(小文字化して部分一致) |
| ai-eval | `-locale` フラグ(全ケースに強制)・ケース `locale` キー・en の edit で base が無い時は `examples/expense_en.json` を seed・`expect.substitution` は 代替 / "replaced" の両方を見る・表に `loc` 列 |
| テスト | `locale_test.go`: 判定(明示 / 検出 / 混在 / 不正値 400)、en create の prompt 行と summary、en edit、en undo、`wantsUndo` / `wantsNewApp` の英語、`summarizeEN` 部品(複数形・冠詞・位置・通知時刻・代替文)、few-shot en の `dsl.Parse` |

## 4. 残メモ

- 判定はかな・漢字の有無だけ。英数字のみの日本語ローマ字発話(例 "kakeibo")は en 扱いになる。iOS 側は端末ロケール or 音声認識の言語を `locale` で明示するのが確実(省略は保険)。
- `summarizeEN` の複数形は naive(`entry → entries`, `box → boxes`, それ以外は +s)。不規則名詞(`person`)は "persons" になるが entity 名は基本的に規則形。
- en の undo は 32 文字上限で文頭一致。"undo the sorting on the list" のような「undo で始まる編集依頼」は undo と誤判定する余地がある(日本語の 「戻して」 と同じトレードオフ)。実機で誤爆が観測されたら prefix を "undo that / undo the last" 等に絞る。
- system prompt は +10.6%(≈1.6K tokens)。ja しか使わない場合も en few-shot を常に載せる。削りたければ en few-shot を home 画面だけ(≈0.8K)にする余地あり。
