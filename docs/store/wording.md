# 避ける言い回しの一覧

#247。ストアの掲載文・スクリーンショット・審査メモ・審査員が見る画面(権限の確認・同意画面・課金画面)で使わない言い方と、その言い換え。

- 理由: App Store Review Guidelines 2.5.2(機能を変えるコードのダウンロード)・4.7(アプリ内のソフトウェア・ネイティブ API を渡すこと)・4.2.6(アプリ生成サービス)・2.5.19(書かれていない機能)・2.3.1(誤解させる説明)。2026 年に Apple は「iPhone のアプリビルダー」「ワンタップで App Store に提出」という売り方を問題にした(調査メモ [P1]〜[P3])。
- 言い換えの軸: 作るのは「アプリ」ではなく「**自分専用の記録帳・ツール**」。「作る」より「用意する」「整える」「直す」。
- 例外: 「Tailor It はアプリです」のように**本体を指す**「アプリ」はよい。

## 1. 避ける言い回しと言い換え

| 避ける(日本語) | 避ける(英語) | 言い換え | 当たる条項 |
|---|---|---|---|
| アプリを作る・アプリ作成・アプリを生成 | make / build / create an app, app maker, app generator | 自分専用の記録帳(ツール)を用意する / set up a tracker made for you | 2.5.2・4.7・4.2.6 |
| アプリビルダー・アプリ開発ツール | app builder, app creator | (言わない)記録帳のアプリ / tracker | 2.5.2(前例) |
| ノーコード・ローコード・プログラミング不要・コードを書かずに | no-code, low-code, without coding | 話すだけで / just by talking | 2.5.2(コードの存在を連想させる) |
| コードを生成・AI が開発する・バイブコーディング | generate code, AI writes the app, vibe coding | AI が画面の形を提案する / AI sets up the screen | 2.5.2 |
| 実行する・動かす(作ったものを) | run, execute (a creation) | 使う / use | 2.5.2・DPLA 3.3.1(B) |
| ダウンロードして機能が増える・追加機能を配信 | download features, new features delivered | (言わない)新しい部品はアプリの更新で増える | 2.5.2・2.5.19 |
| App Store に公開・リリース・ストアに出す | publish to the App Store, release, submit | (言わない) | 4.2.6・2.5.2(前例) |

| 何でも作れる・どんなアプリも・無限に | build anything, any app, unlimited | 記録・チェックリスト・家計簿などを / trackers, checklists, budgets | 2.3.1(検証できない主張) |
| アプリが生まれ変わる・変身する | the app transforms | 記録帳の形が変わる / it changes right away | 2.5.2(本体の機能が変わると読まれる) |
| 単体アプリにする・独立したアプリ | standalone app | (審査用の版には無い。言わない) | 4.2.6 |
| 共有・みんなで使う・友達と | share, with friends | (審査用の版には無い。言わない) | 1.2・2.5.19 |

## 3. 審査用の版で外した機能に触れる言葉

審査用の版(#245 / PR #284)で外した機能は、ストアの文・スクショ・審査メモのどこにも書かない(書くと 2.5.19 の「書かれていない機能」の逆で、2.3 の「無い機能を書いた」になる)。

| 外した機能 | 書かない言葉 |
|---|---|
| リリース申請 | 単体アプリ・リリース・申請 / standalone, release request |
| 「探す」の公開カタログ | 探す・公開・みんなの作品 / discover, publish, explore |
| 共有リンク | 共有・シェア・リンクを送る・QR で渡す / share link |
| HealthKit | ヘルスケア・歩数・体重の連携 / Health, steps |
| 道のりの記録 | ルート・散歩の道のり・バックグラウンド / route tracking |
| 近くの端末との共有 | 近くの端末・AirDrop のように / nearby |
| 撮影 | カメラで撮って記録 / take a photo(写真ライブラリから選ぶ、とだけ言う) |
