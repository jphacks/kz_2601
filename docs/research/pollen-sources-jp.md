## 結論(推奨・未確定)

- **推奨・未確定**: 鍵の要らない feed にできる日本の花粉の出どころは、今回の調査では見つからなかった。
- 予報が要るなら、Google の Pollen API(日本はスギ・ヒノキに対応)が、鍵 1 つで runner の口に載せやすい。表示・保存の規約は **未確認**なので、入れる前に確かめる。
- 環境省の観測は 2021 年で終わっており、過去データのファイルだけが残る。予報には使えない。
- 民間の気象会社の法人 API は、問い合わせ → 見積もり → 契約の形で、生成アプリの小さい用途には重い。

## 候補ごとの注

- **Google Pollen API**: [概要](https://developers.google.com/maps/documentation/pollen/overview)に、日ごとの花粉の指数・最大 5 日の予報・1 km 格子とある。[対応の国と植物](https://developers.google.com/maps/documentation/pollen/coverage)に日本(JP)があり、種類は「草・木」、植物は「草・スギ・ヒノキ」。雑草(ブタクサ等)は日本では対象外。対応外の場所は 400 で返る(FAQ)。健康の助言は WHO などを出どころとし、Google は健康データを処理せず個人向けの結果も出さないと書いている。(確認日 2026-11-13)
- **WxTech**: [提供の流れ](https://wxtech.weathernews.com/products/data/flow/)は問い合わせ → 提案 → 契約・導入(API キー発行を含む)。花粉データだけの仕様はこのページに無い。2021 年の仕様は [2021-01-20 の発表](https://jp.weathernews.com/wp-content/uploads/2021/01/20210120.pdf)の検索抜粋による。(確認日 2026-11-13)
- **無償公開**: [2022-02-07 の発表](https://jp.weathernews.com/wp-content/uploads/2022/02/20220207-kafun.pdf)(PDF の本文は取得できず、検索抜粋による。**未確認**)。
- **環境省**: [過去の飛散結果](https://www.env.go.jp/chemi/anzen/kafun/kakohisan.html)は令和 6・7 年シーズンの分が PDF・Excel で掲載、それ以前は「はなこさん」の過去データ一覧。事業は 2021-12-24 に終了。(確認日 2026-11-13)

## 季節だけのデータの扱い

- 花粉はスギ・ヒノキが主に 2〜5 月。シーズンの外は、予報の出どころが 0 や空を返す。
- 案(推奨・未確定): シーズンの外は「いまは飛散の少ない時期」と**出どころの値のまま**返し、数を作らない。出どころがエラーなら、既存の方針どおり 502 `upstream_unavailable` にする。
- 対応外の場所(Google は 400)は 400 `bad_request` に写す。
- 出どころの有効期間・更新頻度を、答えの「取得時刻」に出す。
- キャッシュの長さは出どころの更新頻度に合わせる(Google は日ごと)。保存してよい期間は規約次第で **未確認**。
