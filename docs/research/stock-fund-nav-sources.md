## 結論(推奨・未確定)

- **推奨・未確定**: 基準価額は、運用会社が公開する API(例: 三菱UFJアセットマネジメントの投信情報 API)を**会社ごとに**使うのが規約上は素直。ただし会社をまたぐ網羅はできない。
- 株価は、日本株は取引所系の配信の規約が厳しい。J-Quants の無料枠は 12 週間遅れで「今の株価」には使えない。遅れた終値を「参考」として出す形が現実的。
- 海外の汎用 API の無料枠は、表示・再配布が許されない形が多い(下記の Twelve Data は無料枠で「内部利用のみ」)。生成アプリの利用者に表示する用途に合うかを必ず規約で確かめる。
- 利用者が自分の鍵を持ち込む形(#1671 の土台待ち)なら、再配布の問題が小さくなる。**未確認**(各社の規約次第)。

## 候補ごとの注

- **J-Quants**: 無料プランは過去 2 年分・12 週間の遅れ。無料の 1 分あたりの回数は 5。出典: [J-Quants の説明](https://jpx-jquants.com/ja/help/data)・[利用規約](https://jpx-jquants.com/ja/termsofservice)・[JPX のお知らせ](https://www.jpx.co.jp/corporate/news/news-releases/6020/20250822-01.html)。ただし、これらのページは今回の取得で本文を読めなかった(HTTP 403)。上の値は検索結果の抜粋によるので、公式で再確認する。(確認日 2026-11-13)
- **三菱UFJ**: 投信情報 API のページに「Web API 利用規約に同意が要る」「仕様書は 2026-06-09 改定」とある。出典: [投信情報 API](https://www.am.mufg.jp/tool/webapi/)・[2018 年の紹介記事](https://www.mufg.jp/profile/strategy/dx/articles/0034/index.html)(対象は約 730 本と記載)。(確認日 2026-11-13)
- **Twelve Data**: 無料の Basic は米国の市場のみの記載。「個人は私用・内部・非商用のみ。会社・組織の利用は事業者向けプランが必要」。出典: [料金ページ(Markdown 版)](https://twelvedata.com/pricing.md)。(確認日 2026-11-13)
- **Alpha Vantage**: [リアルタイム・15 分遅れのデータの方針](https://alphavantage.co/realtime_data_policy)(米国市場の話)。日本株は **未確認**。
- **投資信託協会**: データの二次利用の規約・API は、検索では見つからなかった。協会の公式サイトで確認が要る。**未確認**

## 投資の助言に見えない表示の注意

法務の判断は **未確認**(人が確認)。表示の方針の案:

- 「参考値」「遅れあり」「投資の助言ではありません」を値の近くに出す。
- 売り買いを促す言い方(おすすめ・買い時など)を AI の生成文に出さない。
- 取得時刻と出どころの名前を必ず出す。
- 株価の予想・評価を生成しない。数字を並べるだけにする。
