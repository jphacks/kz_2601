## 0. 前提と原則

| 項目 | 内容 |
|---|---|
| 端末 | iPhone 13 実機(主)+ 予備端末(`METAMON_MOCK=1` ビルド = 同梱サンプル DSL で動く全モック) |

## 4. 逃げ道の全体像(3 層)

| 層 | 状況 | 操作 | 所要 |
|---|---|---|---|
| 1. その場で | 音声が取れない | 音声シート下部の**文字入力**に切替 → 上表の文言を貼る | 10s |
| 1. その場で | 生成が 20 秒を超える / エラー toast | 短い発話(「家計簿」)で再送。**同じ長文を繰り返さない** | 10s |
| 1. その場で | `version_conflict`(409) | iOS が自動で 1 回リトライ。toast が出たらもう一度だけ送信 | 5s |
| 2. 端末を替える | ai-stg が落ちている / Wi-Fi 死亡 | **予備端末(`METAMON_MOCK=1` ビルド)** に持ち替える。`MockAIClient` が発話のキーワード(家計簿/トレ/散歩)で同梱サンプル DSL(`docs/dsl/examples/*.json`)を 1.2 秒で返す。改変は効かないので「改変は動画で」と言う | 15s |
| 2. 端末を替える | Wi-Fi はあるが Cloud Run が落ちている | Mac で `PORT=8081 go run ./cmd/ai` を起動し、LAN IP 向けにビルド済みの予備端末(前日に用意) | 30s |
| 3. 動画 | 実機が完全に死んだ | 提出動画の該当シーンを再生し、口頭で補足 | — |
