# デスクトップ版の機能の突き合わせの表(iOS の Features の入口 × デスクトップ)

iOS の `ios/Metamon/Features/` の入口を 1 行ずつ並べ、デスクトップ版(`desktop/`・Windows・Linux)の状態と Issue 番号を書く。部品・アクション(DSL の type)ごとの対応は別の表 [docs/desktop/support-matrix.md](../../docs/desktop/support-matrix.md)、動かし方と「今できること」は [../README.md](../README.md)。親: #1738。

- 調べた元: `origin/epic/god`(8cd11b78b)の `desktop/app/src/main/kotlin`・`desktop/services`・`desktop/README.md`・`docs/desktop/*`。開いている PR は 2026-11-13 に `gh pr list` で見た(PR の base が epic/god でない物は、別の PR の上に積んである)。
- コード・決定事項は変えていない。「推測」と書いた所は確かめていない。

## 今の絵

- デスクトップは今、DSL を描いて端末に記録を残す所までで、**サインイン・会話(作る・直す)・共有・課金・設定の画面は入っていない**(README「サインインはまだ無い」)。表の「無い」の多くはサインインの先にある物(推測)。
- 開いている PR の多くは、規則だけ(描画なし)・API クライアントの取り込み・画面の 1 枚、の順に細かく分けてある。
